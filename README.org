*** Setup

+ Install the dependencies:

#+BEGIN_SRC bash
pnpm install
#+END_SRC

*** Get started

+ Start the dev server [http://localhost:5500](http://localhost:5500).

#+BEGIN_SRC bash
pnpm dev
#+END_SRC

+ Build the app for production:

#+BEGIN_SRC bash
pnpm build
#+END_SRC

+ Preview the production build locally:

#+BEGIN_SRC bash
pnpm preview
#+END_SRC
